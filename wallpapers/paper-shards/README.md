# Paper Shards

Рваные бумажные карточки в стиле поп-арт коллажа, разбросанные внахлёст по всему экрану. Каждая карточка медленно и бесконечно вращается вокруг своего центра — у всех своя скорость и направление.

### Пиксельный эффект

Сцена рендерится через **WebGL**: сцена дополнительно сжимается до низкого разрешения и растягивается обратно без сглаживания, из-за чего края становятся по-настоящему острыми, без размытых переходов между цветами. Степень пикселизации настраивается.

### Экран блокировки

Когда устройство заблокировано, карточки плавно становятся немного крупнее, а их контур — заметно жирнее. Оба параметра настраиваются отдельно. При разблокировке всё плавно возвращается обратно.

### Зарядка

При подключении зарядного устройства все карточки одним движением слегка подталкивает вверх, будто прошла волна, — а затем они плавно, с лёгкой пружинистой инерцией, оседают обратно на место.

### Настройки

Доступны: скорость вращения, интенсивность пиксельного эффекта, толщина обводки карточек, сила увеличения и утолщения обводки на блокировке, зерно/дизеринг поверх сцены, пять готовых цветовых палитр, а также переключатель **Material You** — при включении цвета берутся из системной акцентной палитры устройства вместо заданной вручную.

### Важно

Обои используют WebGL. В «Простом режиме отрисовки» (Настройки → Эксперименты в Wallify) WebGL не отображается — на устройствах с этим режимом вместо сцены будет чёрный экран. Для нормальной работы простой режим должен быть выключен.
