# Material 3 Shapes (Lite)

Энергоэффективная версия Material 3 Shapes: фигуры оживают на пару секунд и замирают.

## Что делает

При включении экрана и разблокировке фигуры плавно расходятся по своим местам за 2.5 секунды,
после чего анимация полностью останавливается. Остальное время на экране статичная картинка,
которая не стоит ни одного кадра.

Цвета берутся из системной палитры Material You и обновляются вместе с темой оформления.

Длительность и повод для запуска анимации заданы в манифесте полями `animationDuration`
и `animateOn`, менять их можно без правки кода страницы.

## Требования

Приложение Wallify версии `1.0.0` и выше. Гироскоп не используется, сеть не нужна.

## Энергопотребление

Комплект помечен `"isLite": true`. После окончания вступительной анимации страница перестаёт
запрашивать кадры вообще, поэтому в покое обои не потребляют ничего сверх памяти под WebView.

Анимация считает время через дельту `performance.now()`, поэтому её длительность не зависит
от выбранной пользователем частоты кадров.
