# Bad Apple Wallpaper

Зацикленное видео `badapple.webm` как живые обои.

## Настройки

- включение или выключение видео;
- звук;
- заполнение экрана, сохранение пропорций или растягивание;
- прозрачность;
- скорость воспроизведения.

> На некоторых устройствах Android WebView может запретить автоматическое воспроизведение звука в фоне. В таком случае видео продолжит играть без звука.

Создано **nector**.
