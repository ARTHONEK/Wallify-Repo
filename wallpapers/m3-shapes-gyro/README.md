# M3 Shapes Gyro Physics

Фигуры Material 3 с физикой гравитации: наклоняете телефон — фигуры скатываются в ту сторону.

## Что делает

Каждая фигура получает ускорение из данных акселерометра, которые движок присылает событием `wallpaperGyroscope`. Наклон по осям `pitch` и `roll` превращается в вектор гравитации, фигуры сталкиваются с краями экрана и теряют часть энергии при отскоке.

Цвета берутся из системной палитры Material You и обновляются вместе с темой оформления.

## Требования

В манифесте выставлен `useGyroscope: true`, иначе движок не регистрирует сенсор. На устройствах без акселерометра фигуры продолжат плавать, но перестанут реагировать на наклон.

Приложение Wallify версии `1.0.0` и выше. Работает без сети.

## Энергопотребление

Цикл отрисовки останавливается по событию `wallpaperPause`, при выключенном экране движок сам замораживает кадры и отключает сенсоры. Постоянный опрос акселерометра всё же стоит батареи — комплект не помечен как энергоэффективный.

На экране четыре фигуры. Это осознанный компромисс: физика с отскоками дороже простого дрейфа.
