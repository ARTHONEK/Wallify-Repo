# Minecraft Wallpaper

Полноценный офлайн-клиент **Eaglercraft 1.12.2** в живых обоях. Клиент запускается из локального файла `game/eaglercraft.html`; после установки сеть для загрузки игры не требуется.

## Как начать

Открой меню Minecraft, создай одиночный мир и играй. Миры сохраняются внутри браузерного хранилища WebView.

## Мобильное управление

- левый стик — `W/A/S/D`;
- правый стик — движение камеры;
- «ПРЫЖОК» — Space;
- «ЛОМАТЬ / СТАВИТЬ» — Shift.

Для корректного рендера должен быть выключен «Простой режим отрисовки» Wallify.

Eaglercraft offline bundle включён локально. Minecraft является товарным знаком Mojang Studios.
